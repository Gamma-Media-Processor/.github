## Spatial Geometry Engine

Unlike traditional static slide presentation software, Gamma-Presentation-Viewer treats documents as continuous flow surfaces divided into discrete card containers. When structural updates occur, the internal layout solver recalculates object boundaries, font metrics, and image bounding boxes in real time. This approach guarantees visual consistency across varying viewport dimensions and prevents clipping or overlap during scaling operations.
